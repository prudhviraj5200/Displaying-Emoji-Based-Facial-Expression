# Displaying-Emoji-Based-Facial-Expression
An AI-based system that detects facial expressions from images or real-time webcam feeds using OpenCV, Haar Cascade, and a CNN-based mini-XCEPTION model. It classifies emotions such as happy, sad, angry, surprise, and neutral, then displays a corresponding emoji for an interactive visual representation.
**Features**
    Real-time facial expression detection
    Image-based emotion recognition
    Face detection using Haar Cascade
    CNN-based emotion classification
    Displays emojis for detected emotions
    Supports 7 emotions: Angry, Disgust, Fear, Happy, Sad, Surprise, and Neutral
**Technologies**
    Python
    OpenCV
    TensorFlow/Keras
    NumPy
    Tkinter
    Haar Cascade
    Mini-XCEPTION CNN

**Applications**
    Interactive applications
    Entertainment
    Educational systems
    Social-media filters
**Project Goal**
    To provide a simple and interactive way to recognize human facial emotions and visually represent them using emojis.
